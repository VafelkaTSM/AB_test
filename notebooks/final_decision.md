# Итоговое решение

**Результат:** конверсия в "treatment" выросла с 21.6% в группе "control" до 24.7% (разница +3.1 п.п., 95% ДИ [0.0105, 0.0500], p = 0.0027 < 0.05)

**Guardrail:** AOV значимо не изменилось (p = 0.1262 > 0.05)

**Реомендация:** изменения для группы "treatment" использовать на всех пользователях.

**Ограничяения:** тест проводился N дней на выборке из M ползователей; cегментный анализ исследовательский, а не подтверждающий, на андроид результаты выглядят хуже.
